# Day 5 - Context Engineering

## What I Learned

Context Engineering is the practice of providing relevant information, goals, constraints, and background before asking AI to perform a task.

Key Learnings:

- Better context creates better outputs.
- AI makes fewer assumptions when context is provided.
- Personalized recommendations become more accurate.
- Context is often more important than the prompt itself.

## Experiment

### Prompt A (Without Context)

Generated a generic 30-day learning roadmap.

### Prompt B (With Context)

Included:

- B.Tech Student
- Web Development Skills
- AI Learning Goal
- 3 Hours Per Day
- Beginner Level
- Practical Learning Style

Generated a personalized roadmap aligned with my goals.

## Comparison

1. Prompt B felt more personalized.
2. Prompt B was more practical and realistic.
3. Context significantly improved the quality of the output.

## Key Insight

The same AI model can produce very different results depending on the context provided.
